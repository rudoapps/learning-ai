💡 Cosas que vas a notar

  • Inglés ≈ 4 caracteres / token. Es la "moneda base" del BPE — fue entrenado con mucho inglés.
  • Español ≈ 2.5–3 caracteres / token. Acentos, ñ y conjugaciones largas dividen más. Pagas un ~30-40% extra por el mismo contenido.
  • Código y JSON: 2–3 c/t. Llaves, comas y comillas son tokens completos. Un schema grande puede salir más caro que un párrafo.
  • Emojis: 2–4 tokens cada uno. Banderas y emojis "compuestos" (👨‍👩‍👧) son los más caros — usan ZWJ y modifiers.
  • Chino, japonés, árabe: ~1.5–2 tokens / carácter. Cada carácter aporta más información, pero el tokenizer no fue optimizado para ellos.
  • El output es 5× más caro que el input. Casi siempre — diseña los prompts para respuestas concisas.
  • Prompt caching cambia las matemáticas. Si reusas el mismo system prompt, el coste de input puede caer 90%. Activa el toggle arriba para verlo.

⚠️ Este tokenizador es una aproximación heurística — no usa la librería oficial de OpenAI/Anthropic/Google. El conteo real puede variar ±10-15%, pero las proporciones y el orden de magnitud son correctos.
